# Password Manager Website

Static website and legal pages for Password Manager, an offline Android app.

## Structure

```text
assets/
	app-icon.png
css/
	style.css
index.html
privacy-policy.html
terms-conditions.html
refund-policy.html
contact.html
README.md
```

## Local preview

Open `index.html` directly in a browser. The pages use relative links and do not
require a build step or JavaScript.

## Before publishing

- Replace `assets/app-icon.png` with the official app icon.
- Complete the marked policy placeholders with the app's actual practices and
	applicable legal requirements.
- Add a monitored support email address to `contact.html`.
